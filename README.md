# Klipp

En Ditto-liknande urklippshanterare för macOS. Klipp sparar allt du kopierar (text, formaterad text, bilder och filer), låter dig söka i historiken med ett kortkommando och klistrar in valt klipp i programmet du kom ifrån. Byggd med Electron så att den kan byggas på en Mac med bara Node installerat, utan Xcode.
